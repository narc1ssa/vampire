# Vampire Survivors Clone

Top-down survival shooter made with Godot 4.7.

## Controls
- **WASD** or **Arrow Keys** — Move
- Shooting is automatic!

## How to play
1. Survive as long as possible
2. Kill enemies to collect XP gems (green)
3. Level up to get stronger
4. Difficulty increases every 10 seconds

## Open in Godot
1. Open Godot 4.7
2. Click **Import**
3. Navigate to this folder and select `project.godot`
4. Press **F5** to play
